# 画像の置き場所

画像は、元の鑑定ページ（`kantei/`）で使っているイルミの画像をそのまま使っています。
同じファイル名で置き換えると、ページ上の画像も変わります。

| ファイル名 | 場所 | 内容 |
|---|---|---|
| `hero.jpg` | ファーストビューの丸窓 | 鍵をくわえた白猫（イルミのメインビジュアル） |
| `door.jpg` | 第I章 | 少しだけ開いた扉と光 |
| `cards.jpg` | 第II章 | 紫の花とタロットカード |
| `intro-moon.jpg` | 第IV章 | 雲間の月 |
| `plan-ume.jpg` | 第V章 Aプラン | 本音の扉 |
| `plan-take.jpg` | 第V章 Bプラン | 未来の扉 |
| `plan-matsu.jpg` | 第V章 Cプラン | 運命の扉 |
| `key.jpg` | 第VIII章 | 古い鍵 |
| `letter.jpg` | 第X章（手紙） | 白い花と万年筆 |
| `about-moon.jpg` | 未使用（予備） | 木々の間の月 |
| `voices/voice_01.jpg` 〜 | 第VII章（今は非表示） | LINE感想のスクリーンショット。名前・アイコンなど個人が分かる部分は必ず隠す |

お客様の声は今は非表示です。画像を置いて `assets/js/config.js` の `voices` に書くと表示されます。
