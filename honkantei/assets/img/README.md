# 画像の置き場所

同じファイル名で置くと、ページ上のプレースホルダ枠が自動で実画像に変わります。

| ファイル名 | 場所 | 推奨サイズ | 内容 |
|---|---|---|---|
| `hero.jpg` | ファーストビューの丸窓 | 1200×1200（正方形） | タロット・灯り・手元など静かな写真 |
| `philosophy.jpg` | 第II章の途中 | 1600×1000（横長） | 窓辺の光・お茶・手帳など、顔が写らない雰囲気写真 |
| `portrait.jpg` | 第X章（手紙）の上 | 1000×1250（4:5） | 今は手紙とキャンドルの写真。ご本人の写真・手元・後ろ姿に差し替えてもOK |
| `voices/voice_01.jpg` 〜 | 第VII章ギャラリー | 縦長スクショのまま | LINE感想のスクリーンショット。名前・アイコンなど個人が分かる部分は必ず隠す |

今入っている写真の出典は `credits.md` にあります。

お客様の声は今は非表示です。画像を置いて `assets/js/config.js` の `voices` に書くと表示されます。
