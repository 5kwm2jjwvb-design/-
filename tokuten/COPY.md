| 1. させる文章にしない | OK | 5章とも「すでに持っている特徴」の描写から書き始めています。「〜しましょう」「〜してください」「今日から」などの命令・宿題の表現は0件です（grepで確認）。 |

| 3. 肯定を直接宣言しない | OK | 「素敵」「そのままでいい」などの直接的な褒め言葉は0件です。肯定はすべて「鑑定をしていると〜方がいます」という情景と、「イルミは〜だと思っています」という見解の中で出しています。 |
| 4. 敵役を作らない | OK | 他の人・他のアドバイス・世の中を否定する文はありません。第伍章の「もう少し軽く考えられたら」は、第三者の助言ではなく本人の心の声として書いています。 |
| 5. 禁止ワード | OK | 汚い／嘘／追わせ／焦ら／愛され度／おばさん／若作り／辛口／絶対：いずれも0件です。「駆け引き」は導入の相談の台詞にだけ出てきます（指示どおり）。「わざと遅らせる」「気のないふり」は、読者が「うまくできないこと」として書いており、勧めてはいません。 |
| 6. 恋の形を否定しない | OK | 不倫・浮気などの語は使っていません。状況には「置かれている状況はそれぞれでも」とだけ触れ、良し悪しの評価をしていません。 |
| 7. 締めは読者の価値で定義する | OK | はじめに・5章・まとめ・あなたの場合は・案内・手紙の締めは、すべて「これは、〜方に向けた／〜方のための〜です」の形です。「嬉しいです」などの書き手側の締めは0件です。 |
| 8. 文体 | OK（注記あり） | です・ます調で、短い文と改行で書いています。絵文字は0です。断定は核の一文と「イルミは〜と思っています」に集めています。※意図して残した断定は2つです。「表れ方は、本当に人それぞれです。」と「そこは、人によって違います。」で、どちらも読者を評価する文ではなく、個人差があるという事実を述べる文です。気になる場合は「〜のように感じます」に変えられます。 |

公式LINE登録特典

# イルミが鑑定で見てきた、大切にされる女性に共通する5つのこと

（CONFIG.gift.subcopy）ご登録、ありがとうございます。  
ここに書いたのは、鑑定の中で  
何度も出会ってきた、ある共通点のお話です。

イルミ｜ご縁を結ぶ霊視占い

`Prologue`


## はじめに

鑑定をしていると、  
ときどき、こんなふうに  
話してくださる方がいます。

> 「私、駆け引きみたいなことが  
本当に苦手で」

少し、申し訳なさそうに。  
まるで、それが自分の  
足りないところであるかのように。

返事をわざと遅らせることも、  
気のないふりをすることも、  
うまくできない。  
やってみようとしても、続かない。

「だから、うまくいかないのかも  
しれませんね」と、  
小さく笑う方もいます。

そのお話を聞くたびに、  
イルミには、  
伝えたくなることがあります。

> **苦手なことは、  
悪いことではないんです。**

苦手だと感じるのは、  
そのやり方が、その人の心の形に  
合っていないから、  
なのかもしれません。

そして、合わないところの裏側には、  
その人にしかないものが  
静かに隠れていることが  
多いように思います。

このあとに書く5つのことは、  
鑑定の中で、大切にされている女性たちに  
何度も重なって見えてきたものです。

新しく身につけるもの、というより、  
もう手の中にあるもの、に  
近いかもしれません。

*これは、自分の苦手なところを責めてきた方に、その見方を少しだけ変えてもらうための内容です。*

`壱`

`One`


## 小さなことにも「ありがとう」が言える

お釣りを受け取るとき。  
エレベーターのボタンを  
押してもらったとき。  
彼がなにげなく、ドアを開けて  
待っていてくれたとき。

気づけば、「ありがとう」と  
口にしている。  
意識して言っているわけではなく、  
こぼれるように、自然に。

鑑定でお話を伺っていると、  
彼からの短いメッセージひとつにも  
「返してくれてありがとう」と  
送っている方がいます。

ご本人は  
「重いと思われていないか心配で」と  
おっしゃるのですが、  
そのやりとりを視ていると、  
相手の方の気持ちが  
ふっとやわらいでいるのを  
感じることがあります。

**― イルミの見方 ―**

イルミは、「ありがとう」は  
相手のしてくれたことを  
当たり前にしない、という姿勢  
そのものだと思っています。

小さな優しさを、  
小さなままで見過ごさない。

受け取った側は、  
自分のしたことが  
ちゃんと届いた、と感じます。  
人は、届いたと感じられる  
相手のそばに  
居たくなるものなのだと、  
イルミは思っています。

*これは、何気ない「ありがとう」を、特別なことだと思わずに続けてきた方のための章です。*

`弐`

`Two`


## 相手の小さな変化に、気づいてしまう

いつもより、返信が少し遅い。  
スタンプだけの返事が、二回続いた。  
電話の声が、ほんの少しだけ低い。

誰に言われたわけでもないのに、  
そういうことに、気づいてしまう。  
そして気づいたあとで、  
「気にしすぎかな」と  
自分に言い聞かせる。

鑑定の中で  
「私、敏感すぎるんです」と  
おっしゃる方は、少なくありません。  
その気づきのせいで、  
眠れない夜を過ごしたことがある方も。

**― イルミの見方 ―**

イルミは、それを  
弱さだとは思っていません。  
相手をよく見ているからこそ  
気づけることだと思っています。

表情の小さな曇りや、  
言葉の選び方のわずかな変化は、  
見ようとしていなければ  
見えにくいものなのかもしれません。

疲れているときに、  
何も言わなくても  
気づいてくれる人がいる。  
それは相手にとって、  
とても心強いことだと、  
イルミは思っています。

*これは、気づいてしまう自分を「考えすぎ」と責めてきた方に向けた、その感じやすさを見つめ直すための章です。*

`参`

`Three`


## してもらったことを、素直に喜べる

好きなお菓子を、覚えていてくれた。  
帰り道に「着いた？」と  
一言だけ届いた。

そういうとき、顔がゆるんでしまう。  
「嬉しい」が、言葉より先に  
表情に出てしまう。

一方で、  
「私なんかに、申し訳なくて」と  
つい恐縮してしまう、という方もいます。

そうお話しされる方を視ていると、  
その恐縮の奥にも、  
ちゃんと喜びがあるのが感じられます。  
嬉しいからこそ、  
どう受け取ったらいいのか  
戸惑ってしまう。  
それも、喜び方のひとつの形  
なのかもしれません。

**― イルミの見方 ―**

イルミは、喜びは  
相手に伝わったときに、いちばん  
温かくなるものだと思っています。

何かをした側にとって、  
相手の顔がほころぶ瞬間は、  
それだけで報われる瞬間  
なのだと思います。

素直に喜べるということは、  
相手の優しさに、もう一度  
意味を与えることなのだと、  
イルミは思っています。

*これは、嬉しさの受け取り方に、少し戸惑ってきた方のための章です。*

`肆`

`Four`


## 人を責める言葉を、選ばない

約束が守られなかった夜。  
待っていた言葉が、  
返ってこなかったとき。

悲しいし、悔しい。  
言いたいことは、たくさんある。

それでも、送る前のメッセージを  
何度も読み返して、  
相手を追い詰めてしまいそうな言葉を、  
そっと消している。

鑑定では、  
「本当は怒ってもいいはずなのに、  
言えない自分が嫌になる」  
というお話を伺うこともあります。

**― イルミの見方 ―**

イルミは、それを我慢や弱さだとは  
思っていません。  
言葉が人の心に残るものだと  
知っているからこその選び方だと  
思っています。

傷ついたときにこそ、  
どんな言葉を選ぶのか。  
そこに、その人の  
言葉への誠実さが  
表れるのだと思います。

責めない、というのは、  
何も感じていない、  
ということとは違って、  
感じたうえで、相手を  
大切に扱おうとしている、  
ということなのかもしれません。

*これは、言えなかった言葉の数だけ、自分を弱いと思ってきた方のための章です。*

`伍`

`Five`


## 一人の人を、深く想い続けられる

考えないようにしていても、  
ふとした瞬間に、思い出してしまう。  
「もう少し軽く考えられたらいいのに」と  
自分で思っても、そうできない。

気持ちを、軽く扱うことができない。

鑑定でお話を伺っていると、  
長いあいだ、ひとりの人を  
想い続けている方に出会います。  
置かれている状況はそれぞれでも、  
その想いの深さは、  
どなたにも共通しているように感じます。

> 「彼を変えたい、というより、  
彼のままを、わかっていたいんです」

そう話してくださる方もいます。

**― イルミの見方 ―**

イルミは、一途さとは、  
相手をまるごと受け止めようとする力  
だと思っています。

相手を、自分の思うように  
変えようとするのではなく、  
その人のままを、見つめようとする。

それは、誰にでもできることでは  
ないと、イルミは思っています。

*これは、想いの深さを、どこかで持て余してきた方のための章です。*

`Afterword`


## 5つ全部でなくて、いいんです

ここまで読んで、  
全部が当てはまる、という方は  
たぶん、少ないと思います。

ひとつだけ、心当たりがあった。  
ふたつめは、少し違うかもしれない。  
それで、自然なことなのだと思います。

鑑定をしていると、  
同じやさしさでも、  
ある方には「ありがとう」として表れ、  
ある方には「気づくこと」として  
表れているのを感じます。  
表れ方は、本当に人それぞれです。

ひとつでも  
「これは、私かもしれない」と  
思えたものがあったなら、  
それが、その方の魅力の表れ方なのだと、  
イルミは思っています。

*これは、そろっていないところを数えてしまう方に向けた、当てはまったひとつを大切にするための章です。*

`For you`


## あなたの場合は

このページに書いたのは、  
鑑定の中で、多くの方に  
重なって見えてきた  
共通の特徴です。

けれど、  
実際にどの特徴が、  
いちばん強く出ているのか。  
それが、今の彼との関係の中で  
どんなふうに働いているのか。  
そこは、人によって違います。

同じ「気づいてしまう」でも、  
ある関係では、それが支えになり、  
ある関係では、ご自身を  
少し疲れさせていることもあります。

そこから先は、  
共通のお話だけでは  
言葉にしきれないところです。

*これは、「私の場合はどうなんだろう」と、ふと思った方のための章です。*
