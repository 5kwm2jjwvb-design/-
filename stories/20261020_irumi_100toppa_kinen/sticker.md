# 3枚目のリアクション：絵文字スライダー

**選んだ理由**：「押してくれた人にDMを送る」流れに対して、指でひと動かしするだけの一番小さな一歩で参加でき、動かした人は発信者にだけ分かるので、そのままDMを送れるため。

## 置く場所
- 画面の中央、本文のすぐ下（ガイド付き画像 `guide/03_guide.png` の点線の丸が中心）。
- 投稿用 `slides/03.png` には印を入れていません。丸を中心に置き、横幅は画面の8割くらいにしてください。

## スタンプに入力する文言（コピー用）
質問：
```
100人突破記念の無料鑑定、受けてみたい？
```
絵文字：
```
🔮
```

## 設定のしかた
1. `slides/03.png` をストーリーズに読み込む。
2. 上のスタンプ一覧から「絵文字スライダー」を選ぶ。
3. 質問欄に上の文言を貼り付け、絵文字を 🔮 に変える。
4. 点線の丸の位置（本文のすぐ下・中央）に置いて投稿する。

## 投稿したあと
- ストーリーズの閲覧者一覧から、スライダーを動かした人を確認できます。
- 動かしてくれた方に、DMで無料鑑定の案内を送ってください。

## DMの例（必要ならコピーして調整してください）
```
スライダー、動かしてくださってありがとうございます。
100人突破記念の無料鑑定のご案内です。
差し支えない範囲で、今いちばん気になっていることを教えてくださいね。
ここでのお話は、ふたりだけのものです。
```
