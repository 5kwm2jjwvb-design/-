# ストーリーズ台本：100人突破記念の無料鑑定と、占いを始めたきっかけ

## いただいた話
- 今フォロワーは115人。100人突破記念として無料鑑定企画を募集する。
- 50人記念の無料鑑定を募集していたら、思っていたより早く100人を超えた（素直な感想）。
- 占いを始めたきっかけ：昔は占いに興味のない、ただの男だった。元カノに連れられて行った占い師さんに「あなた、占い向いてるよ」と言われた。
- 少し一歩踏み出すだけで人生は変わる。これは自分の経験からも言える。
- 感謝を込めて無料鑑定企画を募集する。興味のある人はリアクションボタンを押してもらい、押してくれた人にDMを送る。

## 骨組み
1. **着地の一文**：「一歩で人生が変わることもあるなら、スライダーを動かすくらいの一歩、今やってみよう。」
2. **通し軸**：**一歩（踏み出すこと）**（1枚目＝無料鑑定を募集していたら100人を超えた／2枚目＝連れられて行った占い師さんのところで言われたひと言／3枚目＝一歩で人生は変わる、スライダーを動かす）
3. **1枚1主張**
   - 1枚目：50人記念の無料鑑定を募集していたら、思っていたより早く100人を超えた。
   - 2枚目：占いに興味のなかった私は、占い師さんのひと言で占いを始めた。
   - 3枚目：一歩で人生は変わる。だから無料鑑定に、スライダーで一歩を。
4. **つなぎ**
   - 1→2：**じゃあ**、せっかくの記念なので、私が占いを始めた話を。
   - 2→3：**その結果**、あのとき一歩踏み出したから今がある。一歩で人生は変わる。
5. **読み手の疑問**
   - 2枚目：「そもそも、この人はどうして占い師に？」→ 元カノに連れられて行った占い師さんのひと言。
   - 3枚目：「そのひと言で、どうなったの？」→ 一歩踏み出して人生が変わった。だから今度はあなたの番。

## 役割配分
1. 導入（100人突破と、記念企画の予告）
2. 深掘り（占いを始めたきっかけ）
3. 着地（一歩で人生は変わる → 感謝の無料鑑定 → 絵文字スライダー → DM）

## 1枚目　導入

### 本文
[[100人突破、]]
[[記念企画。]]

50人記念の無料鑑定を募集していたら、
思っていたより早く100人を超えて、
今は115人になりました。

{{こんなに早いとは、思っていなくて。}}

- 字数：79字／6行
- デザイン：見出し強調（暗い画面に白文字・文字は上）。左揃え。
- 背景画像のイメージ：夜、白い壁の寝室にともる小さなランプを引きで。引き／夜の灯り／生成り・白っぽい。
- 使った技法：具体的な数字（50人→100人→115人）、権威性（想定より早く増えている実績）、限定性（100人突破の記念企画）

## 2枚目　深掘り（占いを始めたきっかけ）

### 本文
[[せっかくなので、]]
[[始まりの話を。]]

昔の私は、占いに興味のない
{{ただの男}}でした。

元カノに連れられて行った占い師さんに、
「あなた、占い向いてるよ」と
言われたのが、始まりなんです。

- 字数：84字／7行
- デザイン：見出し強調（暗い画面に白文字・文字は上）。1・3枚目と並んだとき同じに見えないよう、見出しを中央揃えにした。
- 背景画像のイメージ：朝の光が差す窓辺と古い椅子を目線の高さで。目線の高さ／朝の光／くすみ色。
- 使った技法：意外性（興味のなかった男が占い師に）、権威性（プロの占い師に「向いてる」と言われた）、自己開示（元カノとのエピソード）

## 3枚目　着地

### 本文
[[一歩で、]]
[[人生は変わる。]]

私の経験からも、本当にそうでした。

感謝を込めて、{{無料鑑定}}を募集します。

気になる方は、下のスライダーを。

動かしてくれた方に、DMを送りますね。

- 字数：81字／6行
- デザイン：見出し強調（暗い画面に白文字・文字は上）。左揃え。本文の下（中心 x540・y1370）に、絵文字スライダーの余白（800×260＋周り60px）を空けた。
- 背景画像のイメージ：ろうそくの灯りの丸テーブルに広げたカードを上から（手だけが写っていて、顔は写っていない）。真上から（やや斜め上）／夜の灯り／くすみ色。
- 使った技法：体験の裏づけ（私の経験からも本当にそうだった）、限定性（100人突破の感謝企画）、ハードルを下げる（スライダーを動かすだけ、DMはこちらから送る）

## 入り口の別案（1枚目だけ差し替え）

### A案（数字の並びから）
50人、100人、
そして今は115人。

思っていたより、ずっと早くて。

### B案（お礼から）
100人突破、
本当にありがとうございます。

実は50人記念の募集中に超えていました。

### 違い（3行）
- 採用案は「記念企画」を見出しにするので、何のストーリーズかが1枚目ですぐ分かります。
- A案は数字の増え方そのもので驚きを伝えますが、企画の話は2枚目以降までお預けになります。
- B案はお礼が先に立つのでやわらかい一方、記念企画だと伝わるのが3枚目になります。

## 通し読み検査

| 確認項目 | 結果 |
|---|---|
| 1→2のつながり | 「こんなに早いとは、思っていなくて。」→「せっかくなので、始まりの話を。」：記念の気持ちのまま、自分の話に入る。OK |
| 2→3のつながり | 「言われたのが、始まりなんです。」→「一歩で、人生は変わる。」：あのとき踏み出したことを受けて、教訓に移る。OK |
| 話題・語り手・時間 | 語り手は「私」のまま。時間は「今（115人）→昔（きっかけ）→今（無料鑑定）」。2枚目は「昔の私は」で時を明示。OK |
| 体験から読み手への橋渡し | 「私の経験からも、本当にそうでした。」の次に「感謝を込めて」で読み手への呼びかけに移る。OK |
| 理由のない言い切り | 「一歩で、人生は変わる」の直後に「私の経験からも、本当にそうでした」（2枚目の体験）で裏づけ。OK |
| 指すもの・説明のない言葉 | 「下のスライダー」は投稿時に置く絵文字スライダー。「始まり」＝占いを始めたきっかけ。OK |
| 着地 | 読み終えると「スライダーを動かすくらいの一歩なら、今やってみよう」になる。OK |
