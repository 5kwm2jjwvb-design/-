# ストーリーズ台本：心にかけた鍵と、今日の一歩（行動の教育）

## 骨組み

### 1. 着地の一文
「イルミさんも鍵をかけたまま何年も動けなかったけど、ひとつの言葉で今にたどり着いたんだ。私の言葉を待っている人もいるなら、後回しにしている場合じゃない。今日ひとつ動こう。」

### 2. 通し軸
**鍵**（心にかけた鍵 → 鍵のすき間から入った言葉 → あなたの言葉が誰かの鍵になる → 鍵をかけたまま足踏みしていた私）

### 3. 1枚1主張
| 枚 | 役割 | この枚で言うこと |
|---|---|---|
| 1 | 導入（過去の自分） | 20代のころまで、私は心に鍵をかけて人を避けていた。 |
| 2 | 深掘り（どん底） | 鍵をかけたきっかけは、信頼していた人の裏切りだった。 |
| 3 | 転機 | 誘われて行った占いで言われた一言だけは、鍵のすき間から入ってきた。 |
| 4 | 見方の転換（読み手への橋） | 今度は、占い師であるあなたの言葉が誰かの鍵になる番。 |
| 5 | 着地（行動） | 迷っている間も、あなたの言葉を待つ人がいる。今日ひとつ動こう。 |

### 4. つなぎ
- 1→2：**じゃあ**、なぜ鍵をかけたのか（きっかけを話す）
- 2→3：**その結果**、鍵をかけた私を、親しくなった女性が占いに誘ってくれた（誘われた先の話へ）
- 3→4：**でも**、なぜその言葉だけが入ってきたのか（理由を話し、読み手へ橋をかける）
- 4→5：**じゃあ**、動けない夜があるあなたはどうするか（行動へ）

### 5. 読み手の疑問（2枚目以降）
- 2枚目：「どうして人を信じられなくなったの？」→ 裏切りがきっかけだった
- 3枚目：「誘われた占いで、何があったの？」→ 一言をもらい、ヒーリングを受けた
- 4枚目：「なんでその言葉だけは入ってきたの？」→ たくさんの生きざまを見てきた人の言葉だったから。次はあなたの番
- 5枚目：「分かってるけど動けない。どうしたらいい？」→ 私も足踏みしていた。でも待っている人がいる。今日ひとつ

```

私は誰のことも信じられずにいました。

{{心に鍵をかけた}}みたいに、
人と深く関わるのを避けていたんです。
```

- デザイン：画像＋文字だけ（暗い画面に白文字・中央）。指定どおり。
- 背景画像：寄り。扉の鍵穴に差さった鍵と、壁に落ちた影（Unsplash 0juktkOTkpU）。くすみ色。鍵は右端に寄せ、文字は暗い壁の上に置いた（文字40px）。
- 使った技法：本音・弱みの開示（人を信じられなかった過去）、通し軸「鍵」の提示

## 2枚目　深掘り（どん底）

```
きっかけは、
[[信頼していた人の裏切り]]でした。

信じていた分だけ、
何を信じたらいいのか分からなくなって。

心に鍵をかけていた私を、
占いに誘ってくれたのが、
親しくなったひとりの女性でした。
```

- デザイン：画像＋文字だけ（暗い画面に白文字・中央）。指定どおり。
- 背景画像：目線の高さ。夕日がカーテン越しに差す寝室（Unsplash VPFi-s-xyXU）。暖色。文字は窓の下のベッドの上（中央より下寄り）に置き、明るい窓にかかる部分だけ暗い楕円を濃くした。
- 使った技法：本音・弱みの開示（裏切りで混乱した気持ち）、人物の登場で続きを読ませる

## 3枚目　転機

```
誘われて行った占いで、
占い師さんがこう言ってくれました。

[[[「あなた本当は、]]]
[[[人と関わること向いてるよ」]]]

ヒーリングも受けて、
その言葉だけは不思議と、
鍵のすき間からすっと入ってきたんです。
```

- デザイン：画像＋文字だけ（暗い画面に白文字）。いただいた言葉を主役として本文の1.5倍に。前後の枚と見え方を変えるため、この枚だけ文字を左揃えにした。
- 背景画像：寄り。暗い中で灯るガラス器のキャンドル（Unsplash Nn-KHurJ1RY）。くすみ色。タロットの写真は白いカードが中央に来て文字と重なるため、占いの場の雰囲気に近いキャンドルを選んだ。
- 使った技法：転機の場面描写、「不思議と」で次の枚の「なぜ」につなぐ

## 4枚目　見方の転換（読み手への橋）

```
たくさんの生きざまを
見てきた人の言葉だったから。

あの一言が今も私を支えています。

今度は、占い師のあなたの言葉が
[[[誰かの鍵になる番]]]です。

なのに、告知を書きかけて
閉じた夜、ありませんか？
```

- デザイン：画像＋文字だけ（暗い画面に白文字・中央）。指定どおり。
- 背景画像：目線の高さ。暮れた紺色の空と、窓に灯りのともる集合住宅（Unsplash _ElhRrxZNVQ）。寒色。文字は上の空に置いた。
- 使った技法：自分ごと化（占い師である読み手が告知を書きかけて閉じる場面）、立場の入れ替え（受け取る側→渡す側）

## 5枚目　着地（行動）

```
私も、鍵をかけたまま
何年も足踏みしていたから分かります。

でも、迷っている間も、
[[あなたの言葉を待つ人]]がいるんです。

{{今日ひとつ動く}}と決めた人は、
右下のハートで教えてください。
```

- デザイン：画像＋文字だけ（暗い画面に白文字・中央）。文字はノートの下の暗い部分に置き、右下のハートの位置（画面下のUI）は空けた。
- 背景画像：寄り。ノートに万年筆で書いている手元（Unsplash wcMysLw5ROM）。ノートは生成り色だが、画面全体は暗め。
- 使った技法：本音・弱みの開示（私も何年も足踏みした）、先延ばしのコスト（待っている人がいる）、小さな一歩（今日ひとつ）、リアクションを宣言にする（ハート＝決めた印）
- リアクションボタン：いいね（ハート）。画面右下のハートを押してもらう。
  - 押したくなる一言（画像の本文に入れたもの）：**今日ひとつ動くと決めた人は、右下のハートで教えてください。**

## 確認してほしい点（創作を避けるため）
- 2枚目「何を信じたらいいのか分からなくなって」は、裏切りのあとの気持ちとして補いました。裏切りの中身・相手は書いていません。
- 3枚目「その言葉だけは不思議と、鍵のすき間からすっと入ってきた」は、その言葉が今も支えになっているという材料から補った感じ方です。
- 5枚目「何年も足踏みしていた」は「20代まで塞ぎ込んでいた」を言い換えたものです。
- 材料に天気や場所などの細かい場面がないため、1枚目は日記風の生活描写を入れず、当時の状態をそのまま書いています。
- 「波動」は自然に入る場所がなかったので使っていません（「鍵」は通し軸として全枚で使用）。

## 通し読み検査
全5枚の本文だけを続けて、初めて読む人のつもりで読みました。

- **境目のつながり**
  - 1→2：「人と深く関わるのを避けていた」→「きっかけは、裏切り」。避けていた理由に答える形で自然につながる。OK
  - 2→3：「占いに誘ってくれたのが、ひとりの女性」→「誘われて行った占いで」。同じ出来事の続き。OK
  - 3→4：「不思議と入ってきた」→「たくさんの生きざまを見てきた人の言葉だったから」。「なぜ？」にそのまま答えている。OK
  - 4→5：「告知を書きかけて閉じた夜、ありませんか？」→「私も足踏みしていたから分かります」。問いを受けて共感から入る。OK
- **ずれ**：語り手は最後まで「私」。時間は20代→転機→今→今日の順で、戻りはない（5枚目の「足踏みしていた」は今の気持ちの理由として過去にふれるだけ）。読み手の話に移るのは4枚目3文目「今度は、占い師のあなたの言葉が」と明示。通し軸「鍵」は全5枚に出ている。OK
- **言い切り・指示語・説明のない言葉**：「あの一言」（4枚目）は3枚目のセリフを指し、直前の「言葉だったから」からも分かる。「誰かの鍵になる番」は直前2文（私が言葉に支えられた）が理由になっている。「告知」は占い師の読み手には説明不要の言葉と判断。OK
- **着地**：最後の1枚で「イルミさんも何年も足踏みしていた」「待っている人がいる」「今日ひとつ」がそろい、着地の一文と同じ気持ちで終わる。OK
