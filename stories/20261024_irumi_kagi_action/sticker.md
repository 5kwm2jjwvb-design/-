# 5枚目のリアクション

## 種類
**いいね（ハート）**
ストーリーズ画面の右下にあるハートです。スタンプを置く必要はありません。

## 押してもらう一言
画像の本文の最後に入れてあります。

```
今日ひとつ動くと決めた人は、右下のハートで教えてください。
```

## 投稿の手順
1. `slides/05.png` を5枚目としてストーリーズに投稿する（スタンプは置かない）
2. ハートの位置は `guide/05_guide.png` の点線の丸のところ（画面の右下、メッセージ欄の右）
3. いいねは、届いた「アクティビティ」で誰が押したか確認できます

## メモ
- 1〜4枚目には、右下に小さく「次へ →」が入っています。5枚目には入れていません。
- ハートを押してくれた方に、あとでDMで「何をすることにしましたか？」とひとこと聞くと、次の会話につながります（任意）。
