# 3枚目のリアクション：DMでキーワード

**選んだ理由**：不倫・浮気の悩みは人に見られたくないので、1対1で誰にも見えないDMに「鑑定」の2文字を送るのが、いちばん抵抗が少なく「今すぐ動く」につながるため。

## 置き場所
- 画面下のメッセージ欄（「メッセージを送信」）をそのまま使います。スタンプは置きません。
- ガイド付き画像 `guide/03_guide.png` の点線の丸が、そのメッセージ欄の位置です。投稿用 `slides/03.png` には印を入れていません。

## フォロワーが送る言葉（本文にすでに入っています）
```
鑑定
```

## 投稿のしかた
1. `slides/03.png` をストーリーズに読み込む。
2. スタンプは追加しない（文字やリンクも足さない）。
3. そのまま投稿する。フォロワーは画面下のメッセージ欄から「鑑定」と送れます。

## 届いたDMへの返信の例（必要ならコピーして調整してください）
```
「鑑定」のメッセージ、ありがとうございます。
無料鑑定のご応募、受け付けました。
差し支えない範囲で、今いちばんもやもやしていることを教えてくださいね。
ここでのお話は、ふたりだけのものです。
```

## 確認してほしいこと
- 本文の「無料鑑定は、DMに『鑑定』の2文字で。」は、DMで受け付ける前提です。応募方法が別（フォームなど）の場合は、3枚目の最後の行とこのリアクションを差し替えてください。
- 返信の例の文言（受付の流れ）は、実際の受付方法に合わせて直してください。
