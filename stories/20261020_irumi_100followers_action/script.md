# ストーリーズ台本：フォロワーさん100人と「ワンタップ」（行動の教育）

## 骨組み（本文より先に作成）

1. **着地の一文**：「ひとりで考えて『また今度』にしてきた私がいちばんもったいなかった。今日こそ、DMに『鑑定』って送ってみよう。」
2. **通し軸**：**押す1回（ワンタップ）**
   - 1枚目：フォローしてくださった方（＝誰かが押したフォロー）
   - 2枚目：100人分のワンタップ／押してくれた1回
   - 3枚目：押すまでは何も変わらない／DMに「鑑定」の2文字
3. **1枚1主張**
   - 1枚目：投稿を始めたら、50人の次はいつの間にか100人になっていて、うれしかった。
   - 2枚目：100人は、誰かが押してくれた1回の積み重ね。恋のもやもやも同じ。
   - 3枚目：押さなければ何も変わらないので、今、DMに「鑑定」と送ってほしい。
4. **つなぎ**
   - 1→2：**じゃあ**、その100人って私にとって何だったのか（ありがとうの中身）。
   - 2→3：**でも**、恋のもやもやが「同じ」ってどういうこと？　→ 押すまでは変わらない。
5. **読み手の疑問**
   - 2枚目：「100人になって、どう感じたの？」→ 1回ずつのワンタップの積み重ねだと気づいて、胸が熱くなった。
   - 3枚目：「恋のもやもやも同じって、どういうこと？」→ 押すまでは何も変わらない。「また今度」の夜の分だけ重くなる。だから今DMで。

骨組みだけを上から読んで「うれしい報告 → 100人＝100回のワンタップ → もやもやもワンタップで動き出す → 今DMで」と通ることを確認してから本文を書きました。

## 役割配分
1. 導入（直近の体験：フォロワーさんが100人に）
2. 深掘り（100人＝100回のワンタップ、そのときの気持ち）＋フォロワーの恋のもやもやへの橋渡し
3. 着地（先延ばしのコスト → 今動く → DMで「鑑定」）

## 材料の扱い
- 使った実話：このアカウントで投稿を始め、50フォロワーに届いたと思ったら100フォロワーになっていた／フォローいただいて嬉しい。
- 天気・場所・食べたものなど、材料にない生活の細部は足していません（実際の日の様子があれば1枚目に1文足せます）。
- 2枚目の「胸の奥がじんわり熱くなりました」は、材料の「嬉しい」を体の感覚で言い直したものです。実感と違えば「顔がゆるみました」などに差し替えてください。
- 「無料鑑定はDMに『鑑定』の2文字で」は、応募方法をDMキーワードにする前提の文です。実際の受付方法が違う場合はこの1行だけ直してください。

## 1枚目　導入（直近の体験）

### 本文
[[フォロワーさんが]]
[[100人に。]]

このアカウントで投稿を始めて、
50人に届いたと思っていたら、
{{いつの間にか倍になっていました。}}

フォローしてくださった方、

- 字数：87字／7行（見出し2行＋本文5行）
- デザイン：見出し強調（暗い画面に白文字・文字は上）。指定どおり。見出しと本文は左揃え。
- 背景画像のイメージ：夜、ランプの灯りがともる寝室を引きで（白いシーツのベッド・紺がかった壁・黄色い灯り）。引き／夜の灯り／生成り・白っぽい。
- 使った技法：具体的な数字（50人→100人）、権威性（実績としての100人。自慢にせず、うれしい報告として出す）、日記の語り口（親近感）

## 2枚目　深掘り＋橋渡し

### 本文
[[100人分の、]]
[[ワンタップ。]]

ある日ふと誰かが押してくれた
1回の、積み重ねなんですよね。

そう思ったら、胸の奥が
{{じんわり熱く}}なりました。

恋のもやもやも、実は同じで。

- 字数：79字／7行（見出し2行＋本文5行）
- デザイン：見出し強調（暗い画面に白文字・文字は上）。指定どおり。1・3枚目と並んだときに同じに見えないよう、この枚だけ見出しを中央揃えにし、文字のかたまりを中央寄せにした。
- 背景画像のイメージ：朝の光が差す窓辺、小さな花瓶の野の花と紫のギンガムリボンを目線の高さで。目線の高さ／朝の光／くすみ色。
- 使った技法：具体的な数字（100人分・1回）、リフレーミング（フォロワー数を「1回ずつの行動の積み重ね」と言い直す）、言いさし（「実は同じで。」）で次の枚へ

## 3枚目　着地

### 本文
[[押すまでは、]]
[[何も変わらない。]]

「また今度」と流した夜の分だけ、
もやもやは重たくなりがちです。

複雑な恋をしてきた私と、
{{ここだけの話}}にしませんか。

無料鑑定は、DMに「鑑定」の2文字で。

- 字数：89字／7行（見出し2行＋本文5行）
- デザイン：見出し強調（暗い画面に白文字・文字は上）。指定どおり。見出しと本文は左揃え。リアクションは「DMでキーワード」なので、画面下のメッセージ欄を使う。メッセージ欄のまわり（画面下）に文字を置かず、本文は上半分で終わらせた。
- 背景画像のイメージ：紺の闇に浮かぶキャンドルの列を上から。真上から（やや斜め上）／夜の灯り／くすみ色（紺）。キャンドルが本文の下に来るよう少し拡大して上寄りにトリミング。
- 使った技法：先延ばしのコスト（「また今度」の夜の分だけ重くなる）、権威性（複雑な恋を経験した占い師）、希少性・限定性（DMなら「ここだけの話」）、具体的な数字（2文字＝行動のハードルの低さ）、ベイビーステップ（送るのは1語だけ）
- 見出しの大きさ：見出し強調の型の「本文の2〜2.5倍」に合わせ、本文44pxに対して見出しは96〜100px。見出しは `[[ ]]`（強調色）として扱い、`[[[ ]]]` は使っていません。

## 入り口の別案（1枚目だけ差し替え）

### A案（問いかけ）
最近、「また今度でいいか」と
スマホを閉じたこと、ありますか？

私は最近、うれしい数字に
出会いました。

### B案（共感）
誰にも言えない恋のことを、
夜ひとりで考えている方へ。

今日は、このアカウントの
小さな報告からさせてください。

### 違い（3行）
- 採用案は実話の日記から入るので、売り込みの気配がなく、新規の人が「誰だろう」と身構えずに読めます。
- A案は「また今度」を1枚目で先に出すので、行動の教育の軸がはっきりしますが、そのぶん少し説教っぽく見えるおそれがあります。
- B案は悩みに直接触れるので刺さる人には早く届きますが、まだ関係の浅い人には距離が近すぎるかもしれません。

## 通し読み検査

全3枚の本文を続けて、初めて読む人のつもりで読み直しました。

| 確認項目 | 結果 |
|---|---|
| 境目のつながり（1→2） | 「本当にありがとうございます。」→「100人分の、ワンタップ。」：お礼の中身を言い直す形で、骨組みの「じゃあ」どおりにつながる。OK |
| 境目のつながり（2→3） | 「恋のもやもやも、実は同じで。」→「押すまでは、何も変わらない。」：「同じ」の中身にそのまま答える。骨組みの「でも」どおり。OK |
| 話題・語り手・時間のずれ | 語り手は最後まで「私」。時間は「投稿を始めて→50人→100人→そう思ったら→今」と前に進むだけ。体験からフォロワーの話への移り目は「恋のもやもやも、実は同じで。」の1文ではっきり示した。OK |
| 通し軸 | 1枚目「フォローしてくださった」／2枚目「ワンタップ」「押してくれた1回」／3枚目「押すまでは」「2文字」。途切れなし。OK |
| 理由のない言い切り | 「押すまでは、何も変わらない」の直後に「『また今度』と流した夜の分だけ重たくなりがち」という理由を置いた。OK |
| 指すものが分からない言葉 | 「そう思ったら」の「そう」は直前の「1回の積み重ね」を指す。「ワンタップ」はすぐ次の文の「押してくれた1回」で説明。「ここだけの話」はDM（1対1）のこと。OK |
| 着地 | 読み終えると「押さないままの夜がいちばんもったいない、今DMしてみよう」になる。着地の一文と一致。OK |
