# 3枚目のリアクション：DMでキーワード

**選んだ理由**：「勇気を出して」の一歩を、誰にも見られない1対1のDMに2文字送るだけにでき、全員受け付ける無料鑑定の応募にそのままつながるため。

## 置き場所
- 画面下のメッセージ欄（「メッセージを送信」）をそのまま使います。スタンプは置きません。
- ガイド付き画像 `guide/03_guide.png` の点線の丸がその位置です。投稿用 `slides/03.png` には印を入れていません。

## フォロワーが送る言葉（本文にすでに入っています）
```
鑑定
```

## 投稿のしかた
1. `slides/03.png` をストーリーズに読み込む。
2. スタンプや文字は足さずに、そのまま投稿する。

## 届いたDMへの返信の例（必要ならコピーして調整してください）
```
「鑑定」のメッセージ、ありがとうございます。
115人記念の無料鑑定、受け付けました。
差し支えない範囲で、今いちばん気になっていることを教えてくださいね。
ここでのお話は、ふたりだけのものです。
```
