# ストーリーズ台本：115人記念と、占いを始めたきっかけ

## いただいた話（音声入力から読み取った内容）
- フォロワーさんが今115人になった。その記念。
- 占いを始めたきっかけ：もともと占いに興味がなかった。行った先の占い師さんに「あなた、実は占いに向いてるわよ」と言われたのがきっかけ。
- ひと言でも人生を変えるきっかけになる。人が変わるときは、そういうひと言から変わっていく。
- 感謝を込めて無料鑑定をする。少しでも興味がある方、応募した方は全員みるので、勇気を出して応募してほしい。

読み取れなかった部分は創作していません（下の「確認してほしいこと」）。

## 骨組み
1. **着地の一文**：「たったひと言で人生が変わることもあるなら、私も勇気を出して、DMに『鑑定』って送ってみよう。」
2. **通し軸**：**ひと言**（1枚目＝お礼のひと言／2枚目＝占い師さんのひと言／3枚目＝そのひと言が始まり、DMに送る「鑑定」のひと言）
3. **1枚1主張**
   - 1枚目：フォロワーさんが115人になった。まずはお礼を言いたい。
   - 2枚目：占いに興味がなかった私が、占い師さんに「向いてる」と言われた。
   - 3枚目：そのひと言が始まりだった。だから感謝の無料鑑定を、勇気を出して受けてほしい。
4. **つなぎ**
   - 1→2：**じゃあ**、その記念に、私のことを少し話します。
   - 2→3：**その結果**、そのひと言が占い師としての始まりになった。
5. **読み手の疑問**
   - 2枚目：「115人の記念に、何を話すの？」→ 占いを始めたきっかけ。
   - 3枚目：「『向いてる』と言われて、どうなったの？」→ それが始まりだった。人が変わるのはこういうひと言から。

## 3枚目　着地

### 本文
[[そのひと言が、]]
[[始まりでした。]]

人が変わるときって、
こんなひと言からなんですよね。

感謝を込めて、{{無料鑑定}}を。

応募された方は、全員お受けします。

勇気を出して、DMに「鑑定」と。

- 字数：90字／7行
- デザイン：見出し強調（暗い画面に白文字・文字は上）。左揃え。リアクションは「DMでキーワード」で画面下のメッセージ欄を使うので、下半分には文字を置いていない。
- 背景画像のイメージ：ろうそくの灯りの丸テーブルに、扇形に広げたカードと手を上から（顔は写っていない）。真上から（やや斜め上）／夜の灯り／くすみ色。
- 使った技法：限定性（115人の記念の、感謝の無料鑑定）、権威性（このひと言で占い師になった本人）、ハードルを下げる（全員お受けします／送るのは「鑑定」の2文字）、行動のうながし（勇気を出して）

誰かのひと言で、
人生が動いたことってありますか？

私には、あります。

### 違い（3行）
- 採用案はお礼から入るので、新規の人にもやわらかく、記念の投稿だとすぐ分かります。
- A案は通し軸の「ひと言」を最初に出すので、物語としての引きは強いですが、1枚目で少し含みを持たせる形になります。
- B案は数字で目を止めますが、お礼の気持ちが伝わるのは2文目からになります。

## 確認してほしいこと
- **行った経緯**：音声の「もつかまずられて行った」が聞き取れなかったため、「なりゆきで行った」としています。たとえば「友達に連れられて」なら、2枚目のその部分を差し替えます。
- **「少年」**：音声では「占いに興味ない少年だった」と聞こえましたが、言い間違いか判断できなかったため、本文では「もともと占いには、まったく興味がなかった」にしています。
- **期限・人数**：「全員お受けします」はいただいた話のとおりです。締め切りや人数の上限は聞いていないので書いていません。あれば3枚目に足せます。
- **応募方法**：DMに「鑑定」と送る形にしています。受付方法が別なら、3枚目の最後の行を差し替えます。
