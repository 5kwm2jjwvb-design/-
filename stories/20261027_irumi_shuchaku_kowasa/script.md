## 骨組み

### 1. 着地の一文
「執着してしまうのは、好きが大きすぎるからじゃなくて、手放すのが怖いからだったのかも。好きな気持ちまで責めなくていいんだ。イルミさんも3年かかったんだな。」

### 2. 通し軸
**3年**（執着していた3年 → その3年で考えていたこと → 3年のあいだに入れ替わったもの → 3年かけて分かったこと → あの3年の私に言いたいこと）

### 3. 1枚1主張
| 枚 | 役割 | この枚で言うこと |
|---|---|---|
| 1 | 導入（過去の自分） | ひとつの恋に3年ほど執着していた。 |
| 2 | 気づき1 | 相手のことを考えているつもりで、頭にあったのは「離れていかないか」という不安だった。 |
| 3 | 気づき2 | 好きな気持ちは、3年のうちに「手放したら何も残らない怖さ」に入れ替わっていた。 |
| 4 | 一本の線につながる（読み手への橋） | 執着は、好きが大きいからではなく、怖さが大きいと起きる。あなたにも覚えがあるはず。 |
| 5 | 着地 | だから好きな気持ちは責めなくていい。見てあげるのは、その下にある怖さのほう。 |

### 4. つなぎ
- 1→2：**じゃあ**、その3年はどんなふうに執着していたのか
- 2→3：**でも**、好きな気持ちはどこへ行ったのか（2枚目の最後の問いに答える）
- 3→4：**その結果**、見え方が変わって分かったこと（2つの気づきが1本につながる）
- 4→5：**だから**、苦しくなるときはどうすればいいか

### 5. 読み手の疑問（2枚目以降）
- 2枚目：「3年も、どんなふうに執着してたの？」→ 考えていたのは相手より「離れていかないか」という不安だった
- 3枚目：「じゃあ、好きな気持ちはどこに？」→ 少しずつ「怖さ」に入れ替わっていた
- 4枚目：「見え方が変わったって、どう変わったの？」→ 執着は怖さが大きいと起きる。あなたもそうでは？
- 5枚目：「自分の恋で苦しくなるとき、どう考えたらいい？」→ 好きは責めなくていい。見てあげるのは怖さのほう


- デザイン：画像＋文字だけ（暗い画面に白文字・中央）。文字は中央より上に寄せ、下にアンケートの余白（840×300＋周り60px）を空ける。
- 背景画像：寄り。小さな白い花を持つ手元（Unsplash m6K4wGEQOq4）。くすみ色。文字は左寄り・左揃えで、花を右に避けた。アンケートの中心は x520・y1420。

## 確認してほしい点（創作を避けるため）
材料は「ひとつの恋に3年ほど執着してしまった」だけなので、次は私が補った内容です。実際と違うところは差し替えます。
- 1枚目「しんどい3年でした」：当時の気持ちとして補いました。
- 2枚目「相手のことを考えているつもりで、頭にあったのは『離れていかないかな』という不安ばかり」：執着していたときの頭の中として補いました。
- 3枚目「好きな気持ちが『手放したら何も残らない気がする怖さ』に入れ替わっていた」、4枚目「3年かけて分かった」、5枚目「あの3年の私に言ってあげたかった」：振り返っての気づきとして補いました。
- 恋の相手・期間の中の出来事・終わり方は書いていません。
- 1枚目は、日記風の生活描写（天気・場所など）を入れていません。材料に当時の具体的な場面がないためです。覚えている場面があれば足せます。
- 商品・サービス・鑑定・相談には一切触れていません。
- 「鍵」は前回の通し軸なので使っていません。「波動」も、理由なしの言い切りになるため入れていません。

## 通し読み検査
全5枚の本文だけを続けて、初めて読む人のつもりで読みました。

- **境目のつながり**
  - 1→2：「しんどい3年でした」→「その3年、私は相手のことを」。同じ3年の中身に入る。OK
  - 2→3：「好きな気持ちは、どこにあったんだろうって」→「好きな気持ちは、3年のあいだに」。問いにそのまま答えている。OK
  - 3→4：「見え方がひとつ変わりました」→「3年かけて分かったのは」。変わった見え方の中身を示す。OK
  - 4→5：「自分の恋だと苦しくなりませんか？」→「だから、好きな気持ちまで責めなくていいんです」。4枚目1文目の「執着は怖さが大きいと起きる」を理由に受けている。OK
- **ずれ**：語り手は最後まで「私」。読み手の話に移るのは4枚目4文目「占い師のあなたも」と明示。時間は「3年の最中→振り返り→今」の順。通し軸「3年」は全5枚に出ている。OK
- **言い切り・指示語・説明のない言葉**：
  - 「怖さ」は3枚目の中で「手放したら何も残らない気がする怖さ」と説明している。
  - 4枚目の言い切りは、2・3枚目の気づきが理由になっている。
  - 5枚目の「その下にある怖さ」の「その」は、直前の「好きな気持ち」を指す。
  - 「どっち」は同じ文の中の「好き」と「怖さ」を指す。
  - OK
- **着地**：好きを責めなくていい、見るのは怖さ、イルミさんも3年かかった、の3つがそろって終わり、着地の一文と同じ気持ちになる。発信者への頼みごとや売り込みはない。OK
