# ストーリーズ台本：執着の下にあった「怖さ」（信用の教育）

## 第2版で直したこと
初版は「イルミの話」と「見ている人の話」が枚の中で何度も入れ替わり、イルミ → 見ている人の流れになっていませんでした。具体的には次の3点です。
- 4枚目：「3年かけて分かった」（イルミ）と「占い師のあなたも」（読み手）が同じ枚に混ざっていた。
- 5枚目：読み手への呼びかけの途中に「あの3年の私に言ってあげたかった」（イルミ）が戻ってきていた。
- 「占い師のあなたも、人の恋なら落ち着いて見られるのに」が、読み手の悩み（好きな人への執着）から少しずれていた。

そこで、構造を次のように一方向にしました。
- **1〜3枚目：** イルミの話だけ。3枚目の最後の1文「これ、私だけじゃない気がして。」で、読み手に橋をかける。
- **4〜5枚目：** 見ている人の話だけ。イルミは出てこない。

## 骨組み

### 1. 着地の一文
「執着してしまうのは、好きが大きすぎるからじゃなくて、なくすのが怖いからかもしれない。好きな気持ちまで責めなくていいんだ。」（そして、イルミさんも3年かけてそこにたどり着いたんだな）

### 2. 通し軸
**「好き」**（好きなはずなのに → 好きな気持ちはどこに → 好きが怖さに入れ替わる → 「好き」より「なくすのが怖い」 → 好きな気持ちまで責めなくていい）

### 3. 1枚1主張
| 枚 | 誰の話 | 役割 | この枚で言うこと |
|---|---|---|---|
| 1 | イルミ | 導入 | 好きなはずなのに、ひとつの恋に3年執着してしんどかった。 |
| 2 | イルミ | 気づき1 | 相手のことを考えているつもりで、頭にあったのは「離れていかないか」という不安だった。 |
| 3 | イルミ → 橋 | 気づき2 | 好きは「手放したら何も残らない怖さ」に入れ替わり、離せなかったのはその怖さだった。私だけじゃない気がする。 |
| 4 | 見ている人 | あなたの場面 | 返事を待って一日中スマホが気になるとき、胸にあるのは「好き」より「なくすのが怖い」かもしれない。 |
| 5 | 見ている人 | 着地 | だから好きな気持ちは責めなくていい。見てあげるのは、その下の怖さのほう。 |

### 4. つなぎ
- 1→2：**じゃあ**、その3年はどんなふうだったのか
- 2→3：**でも**、好きな気持ちはどこへ行ったのか（2枚目の最後の自問に答える）
- 3→4：**たとえば**、あなたにもこんな日がないか（「私だけじゃない気がして」を具体化する）
- 4→5：**だから**、責めるところはどこか（「責めるところが違ってきます」に答える）

### 5. 読み手の疑問（2枚目以降）
- 2枚目：「3年も、どんなふうに執着してたの？」→ 考えていたのは相手より不安だった
- 3枚目：「じゃあ、好きな気持ちはどこに？」→ 怖さに入れ替わっていた。離せなかったのはその怖さ
- 4枚目：「私だけじゃないって、どういうこと？」→ 返事を待つ日のあなたの胸にあるのも、怖さかもしれない
- 5枚目：「責めるところが違うって、どこを？」→ 好きは責めなくていい。見てあげるのは怖さ

```

```

- デザイン：画像＋文字だけ（暗い画面に白文字）。文字は上の空。

## 5枚目　着地（読み手の見方が変わる）

```
好きな気持ちまで、
責めなくていいんです。

そっと見てあげたいのは、
[[[その下にある怖さのほう]]]。

あなたの執着は、
「好き」と「怖さ」どっちに近い？
```

- デザイン：画像＋文字だけ（暗い画面に白文字・左揃え）。文字は中央より上、下にアンケートの余白（840×300＋周り60px）を空ける。
- 背景画像：寄り。小さな白い花を持つ手元（Unsplash m6K4wGEQOq4）。くすみ色。
- 使った技法：見方の転換の着地（責める対象を「好き」から外す）、読み手が自分を振り返れる二択の問い
- リアクションボタン：**アンケート**
  - 選んだ理由：「好き」と「怖さ」の二択で自分の執着を振り返ることが、そのまま今回の気づきを持ち帰ることになり、新規の人も1タップで答えられるため。
  - 問い：あなたの執着、近いのはどっち？
  - 選択肢：好きだから／手放すのが怖いから

## 通し読み検査
全5枚の本文だけを続けて、初めて読む人のつもりで読みました。

- **誰の話か**：1〜3枚目はすべてイルミ（「私」）の話です。3枚目の最後の1文で「私だけじゃない」と橋をかけ、4〜5枚目はすべて読み手の話です。イルミの話には戻りません。OK
- **境目のつながり**
  - 1→2：「しんどい3年でした」→「その3年、私は」。同じ3年の中身に入る。OK
  - 2→3：「好きな気持ちは、どこにあったんだろうって」→「好きな気持ちは、3年のあいだに」。自問にそのまま答える。OK
  - 3→4：「これ、私だけじゃない気がして」→「たとえば、返事が来ないだけで」。「たとえば」で読み手の場面に具体化する。OK
  - 4→5：「責めるところが違ってきます」→「好きな気持ちまで、責めなくていいんです」。どこを責めなくていいかに答える。OK
- **ずれ**：時間は「3年の最中→振り返り→読み手の今」の順。通し軸「好き」は全5枚に出ている。OK
- **言い切り・指示語・説明のない言葉**：
  - 「怖さ」は3枚目の中で「手放したら何も残らない」と説明している。
  - 3枚目の「その怖さ」は直前の文の「怖さ」を指す。
  - 4枚目の「そのとき」は直前の「一日中スマホが気になる日」を指す。
  - 5枚目の「その下」は直前の「好きな気持ち」の下を指す。
  - 5枚目の言い切り「責めなくていい」の理由は、4枚目の「胸にあるのは怖さのほうかもしれない」。
  - OK
- **着地**：好きは責めなくていい、見るのは怖さ、の2つで読み手の見方が変わって終わる。イルミさんが3年かけてたどり着いた気づきだということは、1〜3枚目で伝わっている。発信者への頼みごとや売り込みはない。OK
