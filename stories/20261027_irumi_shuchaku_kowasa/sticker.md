# 5枚目に置くスタンプ

## 種類
**質問ボックス**

## 質問ボックスに入力する一文（いただいた文言のまま・そのままコピー）

```
もし誰にも言えない悩みを抱えられていたら、ここに書き込んで、1人だけで抱えない悩みにしませんか
```

### 長くて入りきらない・文字が小さくなりすぎるとき用（短い案）
```
誰にも言えない悩み、ここに置いていきませんか
```

## 置き方
1. `slides/05.png` を5枚目としてストーリーズに読み込む
2. 上のスタンプボタンから「質問」を選ぶ
3. 初期の文言を消して、上の一文を貼り付ける
4. スタンプの中心を `guide/05_guide.png` の点線の丸の位置（横の真ん中、文字とバラのあいだ）に合わせる
5. 大きさは、文字とバラにかからない範囲で調整する

## メモ
- 1〜4枚目には、右下に小さく「次へ →」が入っています。5枚目には入れていません。
