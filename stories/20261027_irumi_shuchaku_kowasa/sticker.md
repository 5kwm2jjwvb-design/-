# 5枚目に置くスタンプ

## 種類
**アンケート**

## 選んだ理由
「好き」と「怖さ」の二択で自分の執着を振り返ることが、そのまま今回の気づきを持ち帰ることになるためです。新規の人も1タップで答えられます。

## 入力する文言（そのままコピー）

質問：
```
あなたの執着、近いのはどっち？
```

選択肢1：
```
好きだから
```

選択肢2：
```
手放すのが怖いから
```

## 置き方
1. `slides/05.png` を5枚目としてストーリーズに読み込む
2. 上のスタンプボタンから「アンケート」を選ぶ
3. 質問と選択肢を、上の文言に書き換える
4. スタンプの中心を `guide/05_guide.png` の点線の丸の位置（横の真ん中より少し左、文字の下）に合わせる
5. 大きさは、文字にかからない範囲で調整する（目安は横幅いっぱいの8割くらい）

## メモ
- 1〜4枚目には、右下に小さく「次へ →」が入っています。5枚目には入れていません。
- 結果が集まったら、次のストーリーズで「どっちが多かったか」を紹介すると、自然な続きになります（任意）。
