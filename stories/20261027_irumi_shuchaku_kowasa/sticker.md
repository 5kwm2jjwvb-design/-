# 5枚目のリアクション

## 種類
**いいね（ハート）**
ストーリーズ画面の右下にあるハートです。スタンプを置く必要はありません。

## 選んだ理由
悩みを二択で答えさせるより、「しがみつく恋より、愛される体質になりたい」という前向きな気持ちを1タップで返せるほうが、読み終えた気持ちのまま押しやすいためです。

## 押してもらう一言
画像の本文の最後に入れてあります。

```
しがみつく恋より、愛される体質になりたい人は、右下のハートを押してください。
```

## 投稿の手順
1. `slides/05.png` を5枚目としてストーリーズに投稿する（スタンプは置かない）
2. ハートの位置は `guide/05_guide.png` の点線の丸のところ（画面の右下、メッセージ欄の右）
3. 誰が押したかは「アクティビティ」で確認できます

## メモ
- 1〜4枚目には、右下に小さく「次へ →」が入っています。5枚目には入れていません。
