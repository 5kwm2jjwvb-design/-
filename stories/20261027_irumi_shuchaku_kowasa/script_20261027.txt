# ストーリーズ台本：誰にも言えない恋（信用の教育）第4版（見た目を手作り風に変更）

## 第4版について
- **本文：** イルミさんが書いた5枚分の文章をそのまま使っています。言葉は変えていません。
- **改行：** 句点（。）ごとに改行し、文と文のあいだに空白の行を入れるルールに合わせて組みました。1行19字を超える行だけ、意味の切れ目で折り返しています。
- **リアクション：** 質問ボックス（5枚目）。

## 見た目（手作り風に変更）
- マーカー（文字の下の帯）は全部やめました。
- インスタのアプリで文字を置いたときのように、1行ずつ半透明の暗い帯を敷いた白文字にしました。帯は角が少し丸く、行の長さに合わせて伸び縮みします。
- 文（空白の行で区切られたかたまり）ごとに、左右の位置を少しずらして、手で置いたような感じにしました。文字は傾けず、すべて水平です。
- 書体は、本文がインスタ標準に近い細めのゴシック体（Noto Sans JP 400）です。主役の一言（1枚目「私には、あります。」と4枚目「どうしてこの人なんだろう」）だけ、手書き風の Zen Kurenaido にしています。
- 強調色（#FFC08A）は、2・3・5枚目の強調の語句と、主役の一言に使っています。
- 文字の後ろの大きな暗い楕円はやめ、読みやすさは行ごとの帯で出しています。帯の上の文字のコントラスト比は、全枚で白8.9:1以上、強調色5.6:1以上です。

## 1枚目　導入（問いかけ）

```
誰にも言えない恋を、
したことはありますか。

[[[私には、あります。]]]
```

- デザイン：画像＋文字だけ（行ごとの帯に白文字）。文字は右上の暗い布の上。「私には、あります。」を手書き風の書体で大きく。
- 背景画像：真上から。暗い布の上の無地のカードとドライの草花（Unsplash Nj9JD8y5vPQ）。くすみ色。出せない手紙を思わせるカード。

## 2枚目　出会い

```
会社員だった頃、
好きなものが同じ女性と出会いました。

話すたびに時間を忘れて、
スマホに名前が表示されるだけで、
[[一日が少し明るくなる]]。

気づけば、心が近づいていました。
```

- デザイン：画像＋文字だけ（行ごとの帯に白文字）。
- 背景画像：引き。朝の光が差し込む、レンガ壁のがらんとした部屋（Unsplash LIMsbquHur0）。暖色。

## 3枚目　結ばれない相手

```
でもその人は、
[[立場的に結ばれることのない相手]]でした。

知った瞬間、胸の奥が冷たくなって、
それでも、想いは止まってくれなかった。
```

- デザイン：画像＋文字だけ（行ごとの帯に白文字）。電球を上に置き、文字は下寄り。
- 背景画像：寄り。暗がりで灯るフィラメント電球（Unsplash RCw5oZPCHiY）。暖色。

## 4枚目　誰にも言えない夜

```
友達にも、職場にも、家族にも言えない。

楽しかった日ほど、
帰り道でひとりになると苦しくなる。

[[[「どうしてこの人なんだろう」]]]
そんな夜を、何度も過ごしました。
```

- デザイン：画像＋文字だけ（行ごとの帯に白文字）。文字は上の空。心の声「どうしてこの人なんだろう」を手書き風の書体で大きく。
- 背景画像：引き。夕日と川、灯台のある街のシルエット（Unsplash 04Av-6vot54）。暖色。帰り道の景色として。
- 改行の補足：「どうしてこの人なんだろう」は句点で終わっていないので、次の文と同じかたまりにしています（間に空白の行を入れていません）。

## 5枚目　ほどけた日 → だから分かる

```
そんなとき、思い立ったように
ふっと占いを受けました。

否定されずに受け止めてもらえて、
ずっと張りつめていたものが、
すっとほどけた。

誰かに打ち明けられる安堵で、
ようやく心が晴れたのを覚えています。

あの経験があったから、
[[誰にも相談できない恋の苦しさ]]が、
分かります。
```

- デザイン：画像＋文字だけ（行ごとの帯に白文字・左寄せ）。文字は上の壁、文字とバラのあいだに質問ボックスの余白（800×380＋周り60px）を空けた。文字量が多いため、本文は指定の下限の40pxで組んでいる。
- 背景画像：寄り。グレーの壁の前のドライローズ（Unsplash 7-vwc5XvkCs）。くすみ色。
- リアクションボタン：**質問ボックス**
  - 入力する一文：もし誰にも言えない悩みを抱えられていたら、ここに書き込んで、1人だけで抱えない悩みにしませんか
