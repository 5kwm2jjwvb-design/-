# ストーリーズ台本：「離れていかないで」の声（信用の教育）

## 第3版で直したこと
- **2〜5枚目の言い回し：** 回りくどさをなくし、イルミさん自身の心の声「離れていかないで」をそのまま言葉にしました。
- **「なくすのが怖い」「その怖さだったんです」：** 遠回しなのでやめ、「離れていかないで」「置いていかれたくない」に替えました。
- **「その下にある怖さ」：** 意味が伝わりにくいのでやめました。5枚目は「苦しいのは『離れていかないで』をひとりで抱えてきたから」にしています。
- **4枚目：** 見ている人の問題が目に浮かぶよう、場面を具体的にしました（既読がつかない、何度もスマホを開く、返事の短さに胸がざわつく）。
- **変えなかった所：** 1枚目と、5枚目の「好きな気持ちまで責めなくていい」はそのままです。
- **構造：** 第2版と同じく、1〜3枚目はイルミさんの話、3枚目の最後で橋をかけ、4〜5枚目は見ている人の話です。

今回は、通し軸を「離れていかないで」、例を既読・返事の短さ、結論を「好きを責めなくていい」、リアクションをアンケートにして、どれとも重ならないようにしました。

## 骨組み

### 1. 着地の一文
「私の執着も、好きすぎるからじゃなくて『離れていかないで』の声だったのかも。好きな気持ちまで責めなくていいんだ。」（イルミさんも3年かけてそこに気づいたんだな）

### 2. 通し軸
**「離れていかないで」**（2〜5枚目に出る。1枚目はOKをいただいた文のまま。「好きなはずなのに」が、この声の前置きになっている）

### 3. 1枚1主張
| 枚 | 誰の話 | この枚で言うこと |
|---|---|---|
| 1 | イルミ | 好きなはずなのに、ひとつの恋に3年執着してしんどかった。 |
| 2 | イルミ | 頭の中はずっと「離れていかないで」で、好きなのか怖いのか分からなかった。 |
| 3 | イルミ → 橋 | あれは好きの大きさではなく、置いていかれたくない気持ちだった。今のあなたも、もしかしたら。 |
| 4 | 見ている人 | 既読や返事の短さで胸がざわつくのは、好きすぎるからではなく「離れていかないで」の声かもしれない。 |
| 5 | 見ている人 | 好きな気持ちは責めなくていい。苦しいのは、その声をひとりで抱えてきたから。 |

### 4. つなぎ
- 1→2：**じゃあ**、その3年はどんな状態だったのか
- 2→3：**でも**、今なら分かる（「分からなくて」→「今なら分かります」）
- 3→4：**たとえば**、今のあなたのこんな場面（「今のあなたも」を具体化する）
- 4→5：**だから**、好きは責めなくていい

### 5. 読み手の疑問（2枚目以降）
- 2枚目：「3年、どんな気持ちだったの？」→ 頭の中はずっと「離れていかないで」だった
- 3枚目：「結局、それは何だったの？」→ 好きの大きさではなく、置いていかれたくない気持ちだった
- 4枚目：「今の私も？ どういうこと？」→ 既読や返事に振り回されるのは、その声かもしれない
- 5枚目：「じゃあ、どう受け止めたらいい？」→ 好きは責めなくていい。苦しいのは、ひとりで抱えてきたから

## 3枚目　イルミの気づき → 見ている人への橋

```
今なら分かります。

あれは、好きの大きさじゃなく、
[[置いていかれたくない]]

そう気づくまで、3年もかかりました。

もしかしたら、今のあなたも。
```

- デザイン：画像＋文字だけ（暗い画面に白文字）。電球を上に置き、文字は下寄り。
- 背景画像：寄り。暗がりで灯るフィラメント電球（Unsplash RCw5oZPCHiY）。暖色。
- 使った技法：気づきの言語化、「3年もかかった」で苦しんだ時間を見せる、最後の1文で読み手へ橋をかける

## 4枚目　見ている人の場面

```
既読がつかないだけで、
何度もスマホを開いてしまう。

返事が短いだけで、
「嫌われた？」って胸がざわついたり。

それは好きすぎるからじゃなく、
{{「離れていかないで」}}の
声かもしれません。
```

- デザイン：画像＋文字だけ（暗い画面に白文字）。文字は上の空。
- 背景画像：引き。夕日と川、灯台のある街のシルエット（Unsplash 04Av-6vot54）。暖色。
- 使った技法：自分ごと化（既読・返事の短さで心が揺れる、見ている人の場面）、問題の可視化、イルミの気づきを読み手の場面に重ねる

## 5枚目　着地（見ている人の見方が変わる）

```
好きな気持ちまで、
[[[責めなくていいんです]]]。

苦しいのは、「離れていかないで」を
ずっとひとりで抱えてきたから。

あなたの執着、近いのはどっち？
```

- デザイン：画像＋文字だけ（暗い画面に白文字・左揃え）。文字は中央より上、下にアンケートの余白（840×300＋周り60px）を空ける。
- 背景画像：寄り。小さな白い花を持つ手元（Unsplash m6K4wGEQOq4）。くすみ色。
- 使った技法：見方の転換の着地（責める対象を「好き」から外す）、苦しさの理由を言葉にする、読み手が自分を振り返れる二択の問い
- リアクションボタン：**アンケート**
  - 選んだ理由：「好きだから」と「離れていかないでほしいから」の二択で自分を振り返ることが、そのまま今回の気づきを持ち帰ることになり、新規の人も1タップで答えられるため。
  - 問い：あなたの執着、近いのはどっち？
  - 選択肢：好きだから／離れていかないでほしいから

## 通し読み検査
- **誰の話か**：1〜3枚目はイルミ（「私」）の話です。3枚目の最後の1文「もしかしたら、今のあなたも。」で橋をかけ、4〜5枚目は見ている人の話です。イルミの話には戻りません。OK
- **境目のつながり**
  - 1→2：「しんどい3年でした」→「その3年、頭の中はずっと」。同じ3年の中身に入る。OK
  - 2→3：「もう自分でも分からなくて」→「今なら分かります」。分からなかったことに、今の目線で答える。OK
  - 3→4：「今のあなたも」→「既読がつかないだけで」。見ている人の具体的な場面になる。OK
  - 4→5：「『離れていかないで』の声かもしれません」→「好きな気持ちまで、責めなくていいんです」。好きが原因ではないので、責めなくていいと受ける。OK
- **ずれ**：時間は「3年の最中→今のイルミ→見ている人の今」の順。通し軸「離れていかないで」は2〜5枚目に出ている（1枚目は変更なしの指示のため入れていない）。OK
- **言い切り・指示語・説明のない言葉**：
  - 3枚目の「あれ」は、2枚目の「頭の中が『離れていかないで』でいっぱいだった状態」を指す。
  - 4枚目の「それ」は、直前の2文（スマホを何度も開く、胸がざわつく）を指す。
  - 5枚目の「責めなくていい」の理由は、4枚目の「好きすぎるからじゃなく」と、5枚目の「苦しいのは〜抱えてきたから」。
  - 「その下にある怖さ」のような分かりにくい言い方は残っていない。
  - OK
- **着地**：好きは責めなくていい、苦しいのはその声をひとりで抱えてきたから、で見ている人の見方が変わって終わる。イルミさんも3年かかったことは3枚目で伝わる。売り込みはない。OK
