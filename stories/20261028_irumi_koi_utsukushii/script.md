# ストーリーズ台本：恋は、あなたを美しくする（2026-10-28）

## このストーリーズについて
- **内容：** イルミさんが話してくれた「対面鑑定で印象に残っている方」の話を、5枚に分けて書き起こしました。
- **書き方：** 言葉はできるだけそのまま残し、話し言葉を読みやすい文に整えています。
- **デザイン：** 10/27版と同じです（写真の上に、1行ずつ半透明の暗い帯を敷いた白文字。書体は Noto Sans JP で統一。文字は水平で、文のかたまりごとに左右だけ少しずらす。強調はテラコッタの #FFC08A）。
- **リアクション：** いいね（ハート）。理由は sticker.md に書いています。
- **配慮：** お客様の話なので、本人と分かる情報（年齢・仕事・地域など）は入れていません。第一印象の部分も、いただいた言い方（「言い方は良くないかもしれませんが」）を残して、やわらかく書いています。

## 構成
| 枚 | 役割 |
|---|---|
| 1 | 導入（あいさつ・ある方の話） |
| 2 | 出会い（初恋の悩み・第一印象） |
| 3 | 変化の始まり |

## 1枚目　導入（あいさつ・ある方の話）

```
いつもご覧いただき、
ありがとうございます。

今日は、対面鑑定で
[[とても印象に残っている]]
ある方のお話をさせてください。
```

- 背景画像：寄り：暗いテーブルに並んだカードと石／くすみ色

## 2枚目　出会い（初恋の悩み・第一印象）

```
その方は、[[初恋の悩み]]で
鑑定に来てくれました。

言い方は良くないかもしれませんが、
身なりをあまり気にされない方、
というのが正直な第一印象でした。
```

- 背景画像：寄り：暗い机の上の手作りのノートとペン／くすみ色

## 3枚目　変化の始まり

```
それでも、何度も
私のところに足を運んでくれて。

想う人との距離が近づくにつれて、
その方は[[少しずつ変わっていった]]んです。
```

- 背景画像：引き：窓辺のテーブルに並んだ2つのティーカップ／暖色

## 4枚目　きれいになっていく姿

```
外見にも気を使われるようになって、
ダイエットもされて。

会うたびに、
[[どんどんきれいになっていく]]姿を
見せてもらいました。

そのとき、改めて思ったんです。
```

- 背景画像：目線の高さ：夕方の光の鏡台とランプ／暖色

## 5枚目　着地（恋はあなたを美しくする）＋ハート

```
恋って、内面だけじゃなく、
外見まで美しくしてくれるんだって。

だから、恋で悩んでいるあなたは、
実はとても素敵なんです。

人に言えない恋を抱えていても、
[[[あなたは、ちゃんと美しい。]]]

少しでもそう思えた人は、
右下のハートで教えてくださいね。
```

- 背景画像：寄り：光の筋の中に咲くピンクのバラ／暖色
