# 5枚目に置くスタンプ

## 種類
**質問ボックス**（質問スタンプ）

## 質問ボックスに入力する一文（そのままコピー）

```
誰にも言えないこと、ここに置いていってね
```

## 置き方
1. 5枚目（`slides/05.png`）をストーリーズに読み込む
2. 上のスタンプボタン →「質問」を選ぶ
3. 初期の文言を消して、上の一文を貼り付ける
4. スタンプの中心を `guide/05_guide.png` の点線の丸の位置（横の真ん中・ベッドの手前あたり）に合わせる
5. 大きさは、文字にかからない範囲で調整する

## メモ
- 画面の本文で「ひとことだけ、下から送ってみてください。」と呼びかけているので、スタンプは必ず文字より下に置いてください。
- 質問ボックスの回答は送った人にしか見えない（シェアしない限り公開されない）ので、気になる方には「匿名ではないけど、ほかの人には見えません」と添えると送りやすくなります。
